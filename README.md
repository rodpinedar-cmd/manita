# 🤝 Manita

Marketplace de servicios a domicilio en Ciudad de México. Conecta clientes con profesionales de confianza: limpieza, belleza, clases, reparaciones y más.

## Stack
- **Frontend:** HTML + CSS + JS (vanilla)
- **Backend:** Supabase (PostgreSQL + Auth)
- **Imágenes:** Unsplash (licencia libre)

## Estructura
- `index.html` — Landing
- `servicios.html` — Listado de profesionales
- `perfil.html` — Perfil + reserva
- `login.html` — Login / registro
- `mis-reservas.html` — Reservas del usuario
- `ser-profesional.html` — Alta de profesionales
- `categorias.html`, `como-funciona.html`
- `supabase_schema.sql` — Esquema de base de datos

## Categorías
Limpieza · Hogar · Belleza · Clases · Mascotas · Cuidados · Otros
